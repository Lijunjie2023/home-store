# 家里有数 · 交互设计稿 v0.1

用浏览器打开 `index.html` 即可体验，不需要安装依赖。桌面展示设计说明和手机画框，手机展示全屏界面。

## 体验路径

1. 首页点击右侧「＋」，创建容器；进入容器后点击「编辑」重命名。
2. 点击「添加物品」，选择本机图片，填写分类、数量和备注。多选照片时可选择合并为一件物品。
3. 点击物品查看详情，选择「移动到其他容器」。
4. 在「查找」中搜索名称、分类或备注，直接查看存放路径。
5. 首页空间筛选右侧「管理空间」或「设置 → 空间管理」支持新增、修改、删除空间。新增的空空间也会保留；名称不得重复或使用「全部」。重命名同步更新所有容器的位置；删除有容器的空间时，必须选择另一个空间接收容器，保留其中的物品与照片。若没有其他空间，请先新增空间。
6. 在「设置」中导出、恢复原型数据，或重置示例。

## 设计边界

- 这是浏览器交互稿，不是安卓安装包。系统照片选择器、权限和安卓返回手势需在原生开发阶段验证。
- 每个容器是一份 App 内相册，不创建手机系统相册。
- 插画为照片占位；用户导入的照片会缩放到最长边 1000 像素并保存到浏览器本地存储。
- 无服务端、账号或云同步；浏览器存储容量有限，不用于保管真实家庭资产数据。
- 空容器可直接确认删除；非空容器需先移动或删除物品。删除原型记录不操作原始照片。
- 界面数据随当前浏览器保存；切换浏览器、清除网站数据或使用不同文件地址可能无法访问原记录。

## 封面与首页布局更新

- 新建或编辑容器时，可选择藤编篮、衣物、玩具、工具箱、织物、数码 6 种默认封面，或从本机选择自定义照片。
- 封面独立于物品照片；新增、移动物品不会自动覆盖容器封面。选择默认封面可以替换已有自定义照片，取消编辑不会保存修改。
- 首页移除品牌标题区；搜索与空间筛选区在列表滚动时保持顶部可见。
- 已在 Chromium 检查默认/自定义封面、取消编辑、刷新保留、自定义切换回默认，以及长列表滚动时顶部区域的位置不变。
- `cover-picker.png` 展示封面选择，`sticky-header.png` 展示列表上滑状态。
