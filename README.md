# 家里有数 · Android 测试版

家庭收纳工具：按空间、容器和物品记录位置，支持照片、分类、备注、搜索、物品移动及本地备份恢复。

## 下载与安装

- [下载 APK 安装包](https://github.com/Lijunjie2023/home-store/releases/download/v0.1.0/home-inventory-0.1.0-debug.apk)
- [打开测试版发布页](https://github.com/Lijunjie2023/home-store/releases/tag/v0.1.0)

将 APK 下载到安卓手机，用文件管理器打开，按系统提示安装。若电脑下载，可通过 USB 或其他文件传输方式发送到手机。

本版为 debug 签名测试版，支持 Android 10 及以上，重点按小米 15 的屏幕布局适配；尚未完成实体小米 15 / HyperOS 验收。使用前建议先用少量测试记录体验。

## 数据说明

记录与导入照片保存在本机，无账号和云同步。可在应用设置页导出含照片的 ZIP 备份。卸载或清除应用数据前请先导出备份。

## 验证

15 项单元测试、6 项 Android 15 模拟器集成检查通过，Android Lint 无问题。模拟器不能替代 HyperOS 真机相册、手势和性能验证。
